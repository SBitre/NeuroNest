1. PROJECT SCOPE
NeuroNest is a web-based AI-powered productivity hub designed to help users
track habits, manage tasks, improve focus, monitor mood, analyze productivity
patterns, and receive AI-driven suggestions. The target audience is students
and young professionals seeking a unified self-improvement platform.

2. OBJECTIVES
- Provide an integrated dashboard for productivity tracking
- Enable habit streaks and goal monitoring
- Offer focus tools (Pomodoro timer)
- Track and visualize mood and well-being
- Deliver personalized AI suggestions

3. SCOPE OF WORK
Week 1–2: HTML5 structure across 11 pages
Week 2–3: CSS3 styling with futuristic glassmorphism/neon theme
Week 4–5: JavaScript interactivity (timer, form handling, dynamic stats)
Optional: Database integration for persistent data
